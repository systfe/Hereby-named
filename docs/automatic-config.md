# 自动区域判断条件

打开世界地图 → 左侧“自动创建区域设置” → “区域判断设置”，在游戏内修改数字、名字和规则，点击“保存并应用”后生效。完整操作见 [游戏内设置与命名](naming-and-settings-0.3.0.md)。高级用户仍可编辑实例目录 `config/hereby-named/automatic.json`，修改 JSON 后点击“重新加载配置”。

`thresholds` 中每类区域都可以分别设置三个字段：

| 字段 | 含义 |
| --- | --- |
| `minimumBiomes` | 至少有几种不同群系；0 表示不使用数量条件 |
| `minimumSpan` | 最低跨度，单位为方块；0 表示不使用跨度条件 |
| `maximumSpan` | 跨度必须小于此值；0 表示没有上限 |

数量和最低跨度是“或”的关系，至少启用一项；最高跨度对两项都生效。跨度取东西、南北长度中的较大者，不是面积。每种群系默认至少占 4 个区块才计数，由 `minimumBiomeChunks` 调整；全部区域还需要达到全局 `minimumSpan`，默认 256 格。

默认规则如下。2026-10-24 测试修订把冻洋、原野、森林和花草甸原来的 3 种改成 5 种，沙漠仍为 4 种。

| 配置键 | 类别 | 至少群系种数 | 或最低跨度 | 最高跨度，不包含 |
| --- | --- | ---: | ---: | ---: |
| `mountain` | 山地 | 0 | 1000 | 0 |
| `ocean` | 大洋 | 0 | 2000 | 0 |
| `frozenOcean` | 冻洋 | 5 | 1000 | 0 |
| `plain` | 原野 | 5 | 1000 | 0 |
| `forest` | 森林 | 5 | 1000 | 0 |
| `flower` | 花草甸 | 5 | 1000 | 0 |
| `desert` | 沙漠、恶地 | 4 | 1500 | 0 |
| `lake` | 完整陆地包围的湖泊 | 0 | 500 | 2000 |

例如，默认森林配置如下。可以只改三个数字，其余类别独立设置：

```json
"forest": {
  "minimumBiomes": 5,
  "minimumSpan": 1000,
  "maximumSpan": 0
}
```

这表示不同森林群系达到 5 种，或者森林跨度达到 1000 格，都可以创建；仍须满足全局最小跨度与连通要求。将 `minimumBiomes` 改成 0 后，就只按跨度判断。

`unlockSpan` 是功能启用所需的连续已记录地图跨度，默认 2000 格；调低它不会跳过各类别自己的门槛。湖泊无论如何调整数字，都仍需已知陆地完整包围，未知边界不会被当成岸线。冻洋并入大洋时同样使用配置中的大洋门槛。

旧配置会自动补齐缺失字段，保留已填写的值、开关和名称白名单。显式填写的无效值会停止自动功能并报告配置错误，不会擅自覆盖。提高门槛不会自动删除已有命名；手动区域和删除保护继续保留。

山地形态命名还支持 `mountainRangeSpan`（默认 2000 格）、`mountainMassifChunks`（默认 4096 个区块）、`mountainRidgeRatioPercent`（默认 180，表示长宽比 1.8）。它们都可在“全局参数”内调整；单个山地最多自动改名一次。

## 本地测试实例

维护者可使用 `scripts/prepare-test-instance.ps1 -SourceInstance 已安装的Fabric实例目录 -Destination 新实例目录` 创建 PCL 可识别的 1.21.1 测试版本。脚本选取地形、地图和性能模组及必要依赖，不复制原存档、私人地图、账号或服务器列表；输出目录必须尚不存在。

追加 `-IncludeVoxy` 可从来源实例选取 Voxy 及必要依赖；来源中如有脏区块保护和跨维度优化补丁，也一起加入。Voxy 是远景渲染器，它导入的远景数据不会自动变成 Xaero 的地表地图记录；自动命名仍读取 Xaero 已记录地表。仅安装 Voxy 不能跳过连续地图探索门槛，也不代表已对 Voxy 数据直接进行自动命名。
