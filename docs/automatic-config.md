# 自动区域判断条件

自动区域只按连续地表跨度判断，不再使用群系种类数量或单个群系区块数作为创建门槛。可在世界地图的自动创建区域设置中修改各类别的最低跨度、跨度上限，以及启用所需的连续已记录跨度。

| 类别 | 最低跨度 | 跨度上限，不包含 |
| --- | ---: | ---: |
| 山地 | 1000 格 | 无 |
| 大洋 | 2000 格 | 无 |
| 冻洋 | 1000 格 | 无 |
| 原野 | 1000 格 | 无 |
| 森林 | 1000 格 | 无 |
| 花草甸 | 1000 格 | 无 |
| 沙漠、恶地 | 1500 格 | 无 |
| 完整陆地包围的湖泊 | 500 格 | 2000 格 |
| 北地 | 1000 格 | 无 |

跨度取东西、南北长度中的较大者，不是面积。各类别还需满足全局最小跨度，默认 256 格。湖泊必须有已知陆地完整包围；未知边界不会被当成岸线。寒冷山地和冻洋保留在各自类别；寒冷湖泊归入北地。明确设置的群系规则优先于北地推断。

区域分析以群系斑块（Biome Patch）为拓扑图节点进行宏观地理识别：面积不大于 3 个区块的微小杂乱群系斑块会被周围主导斑块完全吞没，消除地图噪点空洞；最多跨过并纳入连续 8 个河流区块（128 方块宽）连接两岸同类斑块，消除两岸缝隙。`unlockSpan` 是自动创建开始工作的连续已记录地图跨度，默认 2000 格。

设置界面包含全量“群系分类”浏览器：动态加载当前世界已注册的所有原版与模组群系，支持按 ID 实时搜索、按已修改/各类别过滤、点击即时循环修改分类，并以增量覆盖（`biomeOverrides`）方式持久化，未修改项保持内置启发式推断。

旧版配置中的 `minimumBiomes` 和 `minimumBiomeChunks` 会在读取时移除，不再影响生成；旧的仅数量门槛会迁移为该类别默认跨度。其余显式跨度设置、开关和名称名单保留。自动区域更新不会删除手动区域。

山地形态命名另有 `mountainRangeSpan`（默认 2000 格）、`mountainMassifChunks`（默认 4096 个区块）、`mountainRidgeRatioPercent`（默认 180，表示长边大于短边 1.8 倍时视为绵延山地）。这些参数与群系数量无关。

## 本地测试实例

维护者可使用 `scripts/prepare-test-instance.ps1 -SourceInstance 已安装的Fabric实例目录 -Destination 新实例目录` 创建 PCL 可识别的 1.21.1 测试版本。脚本选取地形、地图和性能模组及必要依赖，不复制原存档、私人地图、账号或服务器列表；输出目录必须尚不存在。

追加 `-IncludeVoxy` 可从来源实例选取 Voxy 及必要依赖；来源中如有脏区块保护和跨维度优化补丁，也一起加入。Voxy 是远景渲染器，它导入的远景数据不会自动变成 Xaero 的地表地图记录；自动命名仍读取 Xaero 已记录地表。
