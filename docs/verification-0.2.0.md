# 0.2.0 验证记录

日期：2026-10-24。此前全部成果以 `v0.1.0` 为基准，本轮开发版本为 0.2.0。

## 自动验证

- Fabric 1.20.1 完整构建通过，23 项测试；Fabric 1.21.1 完整构建通过，25 项测试。均以 JDK 21 执行，输出分别为 Java 17 和 Java 21 字节码。
- 新增几何边界测试先观察失败，再实现缓存的填充、边界和标题布局。256 × 256 的连续区域产生 1 个填充矩形、4 条外边界，面积仍为 65,536 个区块。
- 孔洞不被填充，标题锚点落在实际所属区块；同色相邻区域保留界线；最大图层覆盖与单层过滤正确；标题随面积和缩放增长，并限制最大字号及视口宽度。
- 不覆盖选择测试先因接口未实现而失败，随后通过。覆盖计划不会修改数据，其他图层不计冲突；不覆盖、强制覆盖及撤销行为均有测试。
- `ADD_PRESERVING` 请求编码往返通过；服务端应用时重新检查归属，拒绝覆盖预览之后才被其他区域占用的区块。
- 新增视口索引回归：16,384 个远近分离的区块，仅返回视口内 1 个填充、4 条边；远处碎片不进入逐帧坐标转换与绘制循环。

## 性能证据

原渲染路径每帧针对可见的每个区块调用地图记录查询并单独填充，使用 floor/ceil 扩张相邻矩形时还会重复混色。现改为共享舍入边界的合并矩形和外轮廓，渲染阶段不逐区块查询地图；已记录地图的采样限制为每 tick 最多 512 次、约 2 ms，纯几何合并在后台完成，缓存用版本号拒绝过期结果。

审查后进一步加入二维包围体索引，渲染阶段只查询视口相交的形状，避免零散区域全维度扫描。已记录区块缓存随当前区域并集裁剪，删除区域不会永久累积已删除的区块。

密集矩形还暴露了区块坐标默认哈希聚集的问题。改进哈希并避免长整数键的坐标异或碰撞后，同一 65,536 区块测试的本机单次耗时从约 4.8 秒下降到约 0.16 秒。该数据包含测试数据构造和几何构建，不是游戏 FPS 的测量，硬件和运行时会影响结果。

## 实机验证

使用隔离的轻量 Fabric 1.21.1 测试目录和全新匿名测试世界，未复制或打开用户原存档。

- 新建两个同图层区域，显示连续底色、外边界及中心名称，放大缩小可观察字号变化。
- Ctrl 长按选中已存在塔区的连续群系，弹出“不覆盖其他区域／覆盖其他区域”选项。
- 选择不覆盖后，塔区归属和名称仍保留，外围群系划入当前区域；底色内不出现单区块网格。
- 初轮实机发现新确认框正文被 1.21.1 背景模糊效果影响，已调整为背景与原生控件绘制之后再绘制正文；区域编辑对话框同步采用此顺序。
- 重启隔离客户端复核确认框正文清晰；按 Esc 后区域文件校验值不变；重新选择“覆盖其他区域”后原塔区被合并到当前区域。

本轮未进行双客户端独立服务器端到端实测；大区域测试验证几何数量与数据规则，未宣称所有复杂形状均只需固定数量的绘制调用。地图初次打开时，未缓存区域会随已记录地图采样逐步显示。
