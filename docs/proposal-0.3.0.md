# 0.3.0 自动创建区域方案

状态：已实现、完成双版本构建及回归测试；实机验证与性能测量范围见 `validation-0.3.0.md`。

## 范围与启用

仅主世界地表。自动功能默认开启，可通过设置关闭；不主动生成未知地形。已记录地图的一片连续区域最大水平跨度达到 2000 格后启用，已有地图计入，不按累计行走距离或相距很远的孤立地图计量。地图关闭时仍可后台渐进处理。

自动命名与选区属于一条处理流程：读取已有地形、分类、归并、检查条件、匹配名称、批量提交。缺资料或缺可用名称时保留候选，不强行建区。

## 分类与归并

以区块中心地表群系和可用高度为证据，结合群系温度、通用标签、内置模组映射及实际起伏。目标整合包作为重点适配和验证对象，不声称涵盖所有模组。缺少分类证据时不创建，支持用户配置分类补充。

区域大小使用东西与南北跨度中较大值，面积比较使用实际区块数。数量条件指候选区域内不同群系 ID 数，每种至少占 4 个区块才计数。任意自动区域最小跨度 256 格；最低跨度和计数过滤可在高级配置调整。

| 类别 | 创建条件 |
| --- | --- |
| 山地 | 跨度 ≥1000 格；不要求狭长，不要求多个群系 ID |
| 大洋 | 海洋连片，跨度 ≥2000 格 |
| 冻洋 | 寒冷海洋群系 ≥3 种，或跨度 ≥1000 格 |
| 原野 | 平原、荒原群系 ≥3 种，或跨度 ≥1000 格 |
| 森林 | 茂密植被群系 ≥3 种，或跨度 ≥1000 格 |
| 大湖泊 | 已知陆地完整包围，500≤跨度<2000 格 |
| 花草甸 | 繁花植被群系 ≥3 种，或跨度 ≥1000 格 |
| 大沙漠 | 沙漠、恶地群系 ≥4 种，或跨度 ≥1500 格 |

分类优先级：水域、山地、花草甸、沙漠、森林、原野。明显寒冷和明显炎热的陆地分开；温和过渡地形按相邻关系归并。海拔用于判断形态，不据此直接切开同一山体。山地名称后缀依形态使用山脉、山岭、山等；取消群山和巨峰类别。

基本采用四邻连接，角接触不连接；允许跨越宽度不超过 32 格的河流连接同类陆地，河流格不归属。狭窄的同类陆地走廊可连接。保持自然轮廓，不以包围盒矩形替代区域。

普通区域达到条件后可创建，并随探索修正。湖泊必须能由已记录资料证明完整陆地包围；封闭水域达到 2000 格后采用大洋/内海命名。未封闭且不足大洋条件的温暖海域暂不命名。

冻洋发现与大洋连接后，若其实际面积小于相连非冻海洋面积的 1/3，则并入大洋；否则保留独立区域。未知地形不计面积。

## 自动演进与人工保护

自动区域默认位于图层 1，不自动建立第二层巨峰。保留已有手动功能和其他维度历史数据，不因本次范围限制删除或改写。

未接管的自动区域可以扩展、合并、更新类别。合并保留最早名称主体，必要时调整类别后缀，并记录被合并区域旧名。自动任务不覆盖手动区域；玩家编辑自动区域后即人工接管，不再自动调整。

删除自动区域后保护原占区块，禁止再次自动创建；新探索部分仍可创建。提供明确操作解除保护。重新分析也不能默默解除保护或修改手动及已接管区域。

关闭只停止后续自动处理，不删除已有区域。修改名称名单只影响后续命名。重新分析须明确确认。

## 名称

完整名字白名单和词根白名单共同组成统一名称池，不分模式。名单条目具有地形及冷暖适用条件，可增删；默认优先完整名字，再用词根组合。素材仅收录实际使用部分，不复制未用内容或私人来源路径。

名称偏温和的西方幻想风格，可筛选真实、神话、游戏地名；不使用与地形不符、极端或依赖世界最高排名身份的名字。未证明火山等特殊地貌时不使用相应专名。

同一命名范围尽量不重名：换名或组合词根，再使用有实际依据的相对方位、同类大小修饰；绝不添加数字后缀。仍无适用名称时暂存候选，等待补充名单，不擅自引入名单外词根。

## 权限与显示

共享数据由服务器统一提交，仅授权玩家探索可以触发共享创建，手动编辑期间暂缓自动提交。无服务端模组时使用本地区域。继续沿用区域名称两行显示及进入标题规则。

颜色按地形类别分配并小幅区分。创建时不弹窗、不刷聊天；玩家已在新建区域内时不立即播放进入标题，下次实际进入再显示。设置界面展示处理状态及待命名数量，提供开关；名单和高级分类规则通过配置文件维护，避免默认界面堆满参数。

## 性能与验证

接受较长的后台分析时间，优先保证游玩流畅。初始预算：主线程每 tick 至多约 1 ms 的可拆分工作，最多一个后台计算任务；卡顿降速，手动编辑暂停提交。增量更新、批量保存同步、限制缓存和候选队列，不在绘制回调分析全图。预算是设计目标，必须实测，不能用线程分离替代验证。

独立轻量实例保留地形模组、必要依赖、性能模组及地图模组，用新世界测试。参考存档只读分析，需要运行时使用副本。对比功能关闭和开启时的帧时间、卡顿、内存、服务器 tick 及后台吞吐；测试初次扫描与持续探索。

验证分类阈值、ID 计数、河流连接、未知边界、湖泊闭合、冻洋比例、区域扩展合并、人工接管、删除保护、名称约束、共享权限、旧数据兼容及性能。实现阶段按项目测试约定补齐公开行为边界。每版导出 Fabric 1.20.1 和 1.21.1 两个安装包。
