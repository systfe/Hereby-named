# 此地名曰（Hereby Named）设计访谈

状态：四轮问题均已回答，用户已授权实现并更名为“Xaero的世界地图 | 此地名曰（Xaero's World Map | Hereby Named）”。完整规格见 requirements.md。

## 用户已明确的行为

- 以当前实例的 Minecraft/Fabric 版本为首要目标，尽量兼容 Minecraft 1.20、1.21.1 等版本。
- 世界地图左侧提供区域编辑模式开关；再次点击退出。用户原文也称区域重命名模式，本文统一称区域编辑模式。
- 编辑模式顶部提供区域选择、新增区域、删除区域、图层选择、新增图层、删除图层和图层显示。
- 新建区域时先指定名字、颜色，随后编辑区块。下拉框及 Tab 可切换当前区域。
- 左键加入区块，右键移除区块；Shift 加鼠标长按拖动用于矩形批量操作；Ctrl 加鼠标长按不动用于群系批量操作。
- 只能编辑已探索并记录的地图区块，包括当前视口之外的区块；未知区块不能加入区域。
- 群系批量选择针对鼠标所在的连续群系，区块按中心地表群系归类；地图数据是否足够支持仍需技术验证。
- 同图层内加入别的区域的区块会转移归属，跨图层允许重叠。
- 默认图层为 1、2，后续新增图层按数字递增。所有图层显示时，重叠区块使用图层数字最大的区域颜色。
- 删除区域或图层均需确认弹窗。
- 图层显示在显示所有、显示此图层、不显示所有之间切换。非编辑模式时在编辑开关上方提供同类按钮，选择显示此图层后还需选择目标图层。
- 鼠标指向区块时，在地图顶部居中、原有群系信息下方显示首尾区域名。例如图层 2、3、4、12 分别有北高、北城、北城南、北城南南石阶，则显示北高和北城南南石阶。
- 用户截图进一步确认：显示位置固定在世界地图屏幕上方居中，坐标行下方原有“平原”等群系文字的下面；区域名跟随鼠标指向的区块更新，文字位置不跟随鼠标。单一区域只显示一行，无区域不显示区域名。
- 支持与 Traveler's Titles 配合，进入区域后显示同样的首尾区域名。
- 用户进一步区分两种显示：地图界面内是上述固定位置的文本；游玩过程中是区域进入标题，等待 Traveler's Titles 的维度、群系标题显示完成后再显示区域的两行文字，第一行套用维度标题样式，第二行套用群系标题样式。未安装 Traveler's Titles 时的内置回退需求仍有效。

## 第一轮已确认（用户逐项回答）

1. 保留当前 Fabric 环境，以完整实现此地名曰为目标，现成模组作为参考。
2. 多人服务器中的命名需要同步给其他玩家；具体方案见第二轮确认结果。
3. 群系操作仅处理鼠标所在连续群系，区块按中心地表群系判定。
4. 操作范围允许超出当前屏幕，但必须是已探索、已记录的地图区块。
5. Traveler's Titles 是可选兼容；未安装时使用内置进入区域标题，两者使用相同的首尾区域名规则。

## 第二轮已确认（用户回复“67891011”，按接受 Q6～Q11 推荐记录）

6. 接受服务器安装此地名曰，统一保存共享区域、校验权限并同步给安装客户端的玩家；服务器未安装时支持本地命名。
7. 所有安装客户端的玩家可查看共享区域；仅 OP 与获授权玩家可以编辑，获授权者可修改全部共享区域。
8. 同一维度同时只有一人编辑，其他人可查看；退出编辑或断线释放编辑权。
9. 以操作者自己的地图记录限制可编辑范围；其他玩家地图上也只绘制其已探索部分，不同步地形地图。
10. 删除图层不重编号，新建图层使用历史最大编号加一，不复用已删除编号。
11. 右键只移除当前区域的区块；支持本次编辑期间撤销／重做，一次拖动或群系填充算一步，同层覆盖可恢复；退出编辑清空历史。

## 第三轮已确认

12. 图层显示模式只过滤地图颜色覆盖，不过滤地图区域文本与区域进入标题。
13. 区域下拉框和 Tab 只切换当前图层的区域；换图层后恢复该层上次选择的区域，没有区域时提示新建。
14. 用户要求保留原来的左键拖动地图平移，不采用中键平移。交互解释：普通左键单击加入区块，左键拖动平移地图，拖动不产生涂抹；Shift 拖动矩形编辑和 Ctrl 长按群系编辑保留。此前建议的 0.5 秒长按阈值未被明确确认，作为可调实现参数，不视为用户指定值。
15. 连续群系按上下左右相邻连接，角相邻不连接；未知区块截断连通性。
16. 首尾区域组合改变并稳定 1 秒后触发标题；原有维度／群系标题正在播放时等待，否则直接显示。等待时只保留最新组合，避免补播旧位置。只有一个区域时使用维度标题样式，离开全部区域不弹标题。
17. 已有区域允许改名、改色，首版不支持迁移所属图层。删除图层时弹窗列出区域数量，确认后连同区域一起删除，支持本次编辑内撤销。

## 第四轮已确认（用户回答“全部推荐”）

18. 区域为二维区块集合，覆盖区块整根垂直柱，不区分玩家高度。
19. 各维度分别拥有图层、区域和图层编号；不跨维度映射坐标。
20. 服务器后来启用共享时保留本地数据备份，使用服务器共享数据，不自动合并或上传；首版不提供导入合并。

## 环境与现成方案初查

- 读取实例及模组元数据：Minecraft 1.20.1，Fabric Loader 0.17.2，Fabric API 0.92.6+1.20.1，Xaero's World Map 1.47.0，Xaero's Minimap 26.6.0，Traveler's Titles 1.20-Fabric-4.0.2。
- 已发现 [Xaero Map Regions](https://modrinth.com/mod/xaero-map-regions)，项目资料描述命名彩色多边形、已探索地图遮罩、进入区域标题与 Traveler's Titles 兼容。
- 其当前公开支持范围为 Forge 1.20.1、NeoForge 1.21.1；未发现适用于本实例的 Fabric 发行版。它不能直接作为本实例的替代品，亦尚未核实其满足本文的区块编辑和图层规则。
- 一手资料：[Modrinth 项目 API](https://api.modrinth.com/v2/project/xaero-map-regions)。此结果为候选初查，不代表已穷尽所有现成模组。
