## 推荐上传包

提交已审阅的当前文件后运行 `scripts/export-source.ps1`。生成的 `dist/hereby-named-0.2.0-source.zip` 仅包含当前提交的源码快照，不包含 `.git`、旧历史、用户游戏数据、开发缓存或本地编译依赖。模组 jar 可单独上传。

**现有 Git 仓库的旧提交仍含原路径和截图。直接 push 此仓库、上传含 `.git` 的整个文件夹或同步所有文件，会暴露这些历史内容。** 本轮没有重写历史或强制推送。若云端需要 Git 项目，可将上述源码包解压到新目录，并在其中新建仓库，从已脱敏的源码创建第一条提交。

构建日志、崩溃报告、游戏区域数据和后续截图可能重新记录本地路径、服务器地址、玩家 UUID 或私人命名；它们不属于源码发布包。
