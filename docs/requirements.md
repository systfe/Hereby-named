# Xaero的世界地图 | 此地名曰（Xaero's World Map | Hereby Named）

状态：四轮访谈已确认；用户已授权实现，并指定最终名称为“Xaero的世界地图 | 此地名曰（Xaero's World Map | Hereby Named）”。首版实现及实际验证范围见 verification.md。

## 目标与环境

为 Xaero's World Map 增加区块区域命名、分层编辑、多人同步及进入区域标题。首要适配当前 Minecraft 1.20.1、Fabric Loader 0.17.2、Xaero's World Map 1.47.0；实例还装有 Xaero's Minimap 26.6.0 和 Traveler's Titles 1.20-Fabric-4.0.2。尽量兼容 Minecraft 1.20、1.21.1 等版本，各版本需独立核实，不能假定同一个 jar 通用。

现成候选 Xaero Map Regions 没有已查到的 Fabric 发行版，且完整图层与区块编辑规则尚未核实。继续开发此地名曰，现成项目作为参考。

## 区域、图层与覆盖

- 一个区域包含名字、标记颜色和区块集合，创建时归属当前图层；必须先创建区域才能编辑。
- 区域覆盖区块全部高度。每个维度的区域、图层和编号相互独立，不换算下界坐标。
- 默认图层为 1、2，新增使用历史最大编号加一；删除不重排、不复用编号。
- 同层同区块只有一个区域：加入当前区域时覆盖原归属；不同层允许重叠。
- 显示所有图层时，重叠位置采用数字最大的图层中对应区域的颜色覆盖。
- 区域可改名、改色；首版不支持迁移所属图层。
- 删除区域需确认；删除图层需确认并显示所属区域数量，确认后删除图层及其全部区域。

## 地图编辑界面

- 世界地图左侧提供“切换区域编辑模式”，再次点击退出。
- 编辑模式顶部提供区域选择、新增区域、删除区域、图层选择、新增图层、删除图层、图层显示。
- 区域下拉框和 Tab 只切换当前层的区域；切换图层恢复该层上次选择，没有区域则提示新建。
- 普通左键单击加入区块，右键移除当前区域的区块，不擦除同层其他区域。
- 保留原有左键拖动平移；应区分单击与拖动，避免平移产生区块涂抹。
- Shift 加左／右键拖动批量加入／移除矩形内区块；Ctrl 加左／右键静止长按批量加入／移除连续群系片区。
- 群系按区块中心地表群系判定，只沿上下左右相邻连通；角相邻不连通，未知区块截断连接。
- 所有编辑限于操作者已探索并记录的区块，可超出当前地图视口；不推测或生成未知地图。
- 支持本次编辑会话内撤销／重做，一次矩形或群系操作算一步；恢复同层覆盖前归属，也支持撤销图层删除。退出编辑后清空历史。

## 地图显示

- 图层显示在“显示所有／显示此图层／不显示所有”间切换。
- 非编辑模式时在编辑开关上方也提供图层显示按钮；选择显示此图层后提供图层选择。
- 显示筛选只影响地图颜色，不过滤两种区域名称显示。
- 地图区域文本固定在屏幕顶部居中、坐标下方原有群系文字的下面；内容对应鼠标指向的区块，位置不跟随鼠标。
- 从该区块全部归属中选出图层数字最小及最大的区域名，小的第一行，大的第二行；仅一个区域则一行，没有则不显示区域名。
- 示例：图层 2 北高、3 北城、4 北城南、12 北城南南石阶同时覆盖时，显示“北高”和“北城南南石阶”。

## 游玩过程中的区域进入标题

- 与地图文本分开触发，按玩家所在区块的首尾区域名显示。
- Traveler's Titles 为可选兼容：安装时等待原有维度、群系标题播放完成，再展示区域标题；未安装时使用内置标题。
- 第一行沿用维度标题样式，第二行沿用群系标题样式；只有一个区域时使用维度标题样式且只显示一行。
- 首尾区域组合变化并稳定 1 秒后触发；原有标题未播放时直接显示。
- 等待时只保留最新组合，避免玩家移动后补播旧地区；离开全部区域不弹标题。

## 单人、本地与多人共享

- 服务器安装此地名曰后统一保存共享数据、校验权限并同步。其他玩家需要安装客户端才能看到扩展显示。
- 所有安装客户端的玩家可查看；仅 OP 与获授权者可编辑，授权者可修改全部共享区域。
- 同一维度同时只允许一人编辑；退出编辑或断线释放编辑权，其他维度可独立编辑。
- 操作者的地图记录限制编辑，查看者也只在自己的已探索地图上绘制颜色；不自动同步地形地图。
- 单人游戏可命名；服务器未安装时也支持本地命名。
- 服务器后来启用共享时保留本地备份并使用共享数据；首版不自动上传、合并，也不提供导入合并。
