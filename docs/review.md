# 首版双轴审查

审查范围：确认需求基线 `750a00e` 至首版实现 `beeaf50`，以及修复后的工作区差异。两位独立审查代理分别检查 Standards 与 Spec，修复后分别复核。

## Standards

- 初审发现 1 项确定问题（P1）：普通 READ 快照可能提前结束编辑锁申请，造成客户端无法编辑、服务器锁遗留。
- 已修复：请求与应答携带关联 ID，只有对应应答完成等待；超时和取消主动在有序连接上发送释放请求，迟到应答不能完成后续申请。
- 补充修复较长自定义维度的 Windows 文件名限制：长名称使用 SHA-256，普通维度继续使用已有文件路径。
- 回归覆盖 READ 先到、跨维度应答、取消后迟到成功、新申请不受旧应答影响、请求应答编解码、长维度保存及备份。
- 复核未发现仍然存在的确定问题；没有仓库明文标准违规或需要优先抽象的代码异味。

## Spec

- 初审发现 1 项确定问题（P2）：没有当前区域时吞掉普通左键按下，阻断地图平移。
- 已修复：空图层普通左键直接交给 Xaero，且不建立涂选手势，释放不会提交修改。
- 复核确认该问题解决，未发现仍然存在的确定 Spec 问题。
- 缩小地图时叶子地图数据尚未驻留可能影响颜色覆盖，尚未取得确定复现证据，保留为游玩回归观察点。

Standards 初审 1 项（最严重 P1），Spec 初审 1 项（最严重 P2）；两项均修复并复核。实测范围及兼容性限制见 verification.md。
