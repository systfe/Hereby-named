# 颈部区域切割、残片门槛淘汰与删除保护开关

## 状态
已接受 (2026-10-25)

## 背景
1. 部分区域（如梅尔文之森）由两处大片森林通过仅 2 个区块宽度的狭窄走廊（颈部）串联，导致总跨度虽然虚高达标，但实际地貌并不属于单一自然区域。
2. 玩家在图层 1 手动圈定区域时侵占自动区域后，剥离出的剩余碎片若远低于跨度门槛（如基朗山残留 688 格），在重新分析时不应作为独立缩水区域保留。
3. 删除自动区域后默认禁止在该范围再次生成，部分玩家希望能够重置并重新探测，需要提供独立开关供玩家选择。

## 决策
1. **颈部检测与切割**：对候选区块集合提取厚度 $\ge 3$ 个区块的核心主体。若存在多个分离的核心主体，通过腐蚀与多源泛滥在 $<3$ 区块的颈部走廊处切断，分裂出的各子分量独立进入跨度门槛审查。大块达标则生成，小块不达标则直接取消。
2. **残片门槛淘汰**：在重新分析或自动应用阶段，若自动区域在扣除玩家手动占领区块后的剩余部分低于生成门槛，直接予以删除注销，不残留碎块。
3. **删除保护开关**：新增 `suppressDeletedRegions` 全局配置（默认 `true`）。开启时删除自动区域记录禁止范围；关闭时删除不记录禁止范围，且重新分析时重置禁止范围，允许整区重新生成。
