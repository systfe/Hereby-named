# 自动区域保留来源，地表记录与权威区域分开

自动区域允许随探索变化，玩家划分则不能被后台任务覆盖。因此在权威区域内保存自动来源、类别、创建顺序和合并旧名，玩家编辑后转为手动管理；删除后的区块保护也属于区域存档，并参与撤销。不能通过名字猜测来源，也不能把这部分信息只放在客户端缓存。

HBN2 读取 HBN1 时将全部旧区域视为手动。相比根据地形重新识别旧区域，这会保留更多人工管理范围，但避免升级时破坏已有划分。回退旧版需要恢复备份；网络通道同步升级为 regions_v3，防止旧客户端误读新版格式。

地形只取 Xaero 已记录主世界地表，不主动生成未知区块。辅助地表缓存可重建且限制大小，不是区域归属的权威来源。共享自动操作仍由服务端验证授权、版本及手动锁，保留本地命名回退能力；分析与保存由单个有界工作线程执行。
