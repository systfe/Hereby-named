# 自动名称来源与寒冷区域优先级

自动命名使用分开的默认名白名单和词根白名单：默认名作为名称主体并追加类别词尾，词根按偏好组合并加类别词尾；为保持名称辨识度，先选未使用的默认名，再选未使用的词根组合，只有唯一名称耗尽后才允许重名。北地覆盖未被玩家群系规则指定的寒冷非山地、非海洋地表，包括寒冷森林、平原和湖泊；这有意让寒冷林地与平原服从气候地域类别，而不是原有植被/地形类别。已存在的自动名称随分类升级保留；北地词尾随机选定后不再变更，既定山地一次性扩张改名仍作为唯一例外。
