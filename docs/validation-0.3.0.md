# 0.3.0 验证记录

## 自动测试与构建

2026-10-24 使用 JDK 21 构建 Fabric 1.20.1 和 1.21.1。完整测试分别为 43 项和 45 项，全部通过；1.20.1 字节码目标为 Java 17。

覆盖连续探索门槛、不同群系 ID 计数、窄河连接、湖泊未知边界、冻洋面积合并、冷热分离、人工接管与删除保护、旧格式升级、权限与锁、名称白名单、移动中自动创建的标题抑制，以及退出后旧排队保存不能覆盖重开世界的数据。

65536 区块连续森林的纯分析单次约 152 ms，在后台执行；20000 个互不连接的小片段也通过有界运行验证。这是领域算法测量，不能换算为游戏 FPS。

## 实机功能

使用独立 Fabric 1.21.1 测试实例与新建世界、匿名测试账户；原参考存档未启动、未写入。保留 BOP、Regions Unexplored、BWG、Nature's Spirit、Terralith、Tectonic、Mystic's Biomes 等地形模组及依赖，配合 Sodium、Lithium、Xaero 地图和 Traveler's Titles。测试实例不随源码或安装包分发。

验证设置入口、开关、主世界地表记录、地图关闭后的采集，以及连续探索门槛：记录存在缺口时保持等待；补齐后约 2500 个已记录区块形成 2400 格跨度，随后自动创建图层 1 的洛瑞原野、洛恩原野、维兰森林。检查了地图着色、外边界、区域名称和群系文本下方的名称。

关闭客户端后，换用最终修复的 jar 重新加载同一测试世界，确认三个区域保留，森林范围继续扩展；设置开关可保存、重新开启不删除已有区域。运行 jar 与构建产物的 SHA-256 一致。没有进行两个独立客户端的多人实机联机验证；权限、锁和数据同步协议由自动测试及代码审查覆盖。

## 性能短测

同一世界、同一位置和视角，6 区块渲染距离、120 FPS 上限，地形已生成，约 2500 个地图样本。使用游戏 F3+L 采集各约 10 秒客户端帧耗时，并使用 JFR 采集同轮服务器 tick；表中堆用量来自客户端指标采样峰值。

| 指标 | 开启自动创建 | 关闭自动创建 |
| --- | ---: | ---: |
| 采样帧数 | 1176 | 1179 |
| 平均帧耗时 | 8.47 ms | 8.46 ms |
| P99 帧耗时 | 10.79 ms | 10.38 ms |
| 最大帧耗时，包含首帧 | 29.92 ms | 11.95 ms |
| 服务器平均 tick | 3.29 ms | 3.02 ms |
| 服务器 P99 tick | 5.88 ms | 4.25 ms |
| 采样堆峰值 | 1216 MiB | 1215 MiB |

这组短测未见明显持续帧耗时增加，但不能证明大地图首次扫描、持续高速探索和完整整合包下没有额外卡顿。跑图建图时曾观察到显著服务器落后；地形生成及模组组合同时参与，不能据此将开销归因于本模组。约 1 ms/tick 是可拆分采样的目标预算，单次等待 Xaero 地图锁仍可能超过预算。更大的长时场景需要后续实测。

## Standards 审查

从 0.2.0 基线进行独立审查。修复旧会话后台写入覆盖新数据、有界工作队列满时漏发广播，以及暂时拒绝被误判为本地存档故障。停止会话会取消排队写入并等待运行中的写入，网络编解码按容量分批提交，广播合并并重试。复查没有剩余阻断项。

## Spec 审查

独立审查后修复完整名字优先级和移动中创建区域误触发进入标题，并增加回归测试。复查没有剩余确定问题。巨峰类别已取消；自动命名仅限主世界地表，未知分类等待用户规则或更多资料。

## 发布与隐私

源码快照排除测试实例、存档、日志、性能原始记录、素材原文件、本机路径及 Git 历史。当前跟踪文件未检出本机用户/游戏绝对路径或凭据模式。Git 提交身份按本机设置；公开 Git 历史与公开源码快照的范围不同，参见 `privacy-audit.md`。

每版同时导出 Fabric 1.20.1 与 1.21.1 安装包。共享协议为 regions_v3，客户端和服务端需同时更新；HBN2 可以读取旧区域数据，回退旧版需要恢复旧格式备份。

## 区域编辑崩溃修复与 Voxy 验证

用户报告点击编辑按钮后，地图渲染通过无效鼠标坐标构造区块，抛出“区块坐标超出世界范围”。沿既有首尾名称查询边界增加方块坐标入口，以报告中的整数极值复现同一异常，修复后无效位置返回空名称，负坐标、正常首尾名称查询及恢复行为通过。两版完整测试为 46 项和 48 项，失败与错误均为 0。

实机复测还发现单人世界被地图暂停时，按世界 tick 处理的共享网络队列停止，进入编辑超时。请求与回复现可由收发、后台完成和有界重试驱动，地图界面 tick 同时推进客户端回复解码，不解除世界暂停。此问题依赖 Fabric 与集成服务器生命周期，现有纯领域测试不能复现该完整路径，采用真实客户端回归验证。实机确认暂停地图中可进入编辑、新建区域、加入区块、显示区域名与删除验证区域。

测试实例从参考整合包增加 Voxy 0.2.15-beta 及两个配套补丁，共 30 个模组 jar；日志确认在 NVIDIA 上创建 Voxy 渲染器，实机进入同一测试存档并执行地图编辑。原参考整合包与存档未写入。Standards 和 Spec 独立复查均未发现剩余确定问题。Voxy 远景不等于 Xaero 地表记录，本轮不新增读取 Voxy 数据的自动命名接口。
