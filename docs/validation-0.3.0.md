## 自动区域连续性缺陷修复

- 修复前新增回归测试首次运行结果：`AutoRegionsTest` 中北地 `AUTO_APPLY` 验证失败，河流间隔用例断言失败；跨度 1000 格用例通过。

## 性能短测

同一世界、同一位置和视角，6 区块渲染距离、120 FPS 上限，地形已生成，约 2500 个地图样本。使用游戏 F3+L 采集各约 10 秒客户端帧耗时，并使用 JFR 采集同轮服务器 tick；表中堆用量来自客户端指标采样峰值。

| 指标 | 开启自动创建 | 关闭自动创建 |
| --- | ---: | ---: |
| 采样帧数 | 1176 | 1179 |
| 平均帧耗时 | 8.47 ms | 8.46 ms |
| P99 帧耗时 | 10.79 ms | 10.38 ms |
| 最大帧耗时，包含首帧 | 29.92 ms | 11.95 ms |
| 服务器平均 tick | 3.29 ms | 3.02 ms |
| 服务器 P99 tick | 5.88 ms | 4.25 ms |
| 采样堆峰值 | 1216 MiB | 1215 MiB |

这组短测未见明显持续帧耗时增加，但不能证明大地图首次扫描、持续高速探索和完整整合包下没有额外卡顿。跑图建图时曾观察到显著服务器落后；地形生成及模组组合同时参与，不能据此将开销归因于本模组。约 1 ms/tick 是可拆分采样的目标预算，单次等待 Xaero 地图锁仍可能超过预算。更大的长时场景需要后续实测。

## 区域编辑崩溃修复与 Voxy 验证

用户报告点击编辑按钮后，地图渲染通过无效鼠标坐标构造区块，抛出“区块坐标超出世界范围”。沿既有首尾名称查询边界增加方块坐标入口，以报告中的整数极值复现同一异常，修复后无效位置返回空名称，负坐标、正常首尾名称查询及恢复行为通过。两版完整测试为 46 项和 48 项，失败与错误均为 0。

实机复测还发现单人世界被地图暂停时，按世界 tick 处理的共享网络队列停止，进入编辑超时。请求与回复现可由收发、后台完成和有界重试驱动，地图界面 tick 同时推进客户端回复解码，不解除世界暂停。此问题依赖 Fabric 与集成服务器生命周期，现有纯领域测试不能复现该完整路径，采用真实客户端回归验证。实机确认暂停地图中可进入编辑、新建区域、加入区块、显示区域名与删除验证区域。

测试实例从参考整合包增加 Voxy 0.2.15-beta 及两个配套补丁；日志确认在 NVIDIA 上创建 Voxy 渲染器，实机进入同一测试存档并执行地图编辑，当前存档的远景导入命令也已完成。原参考整合包与存档未写入。Standards 和 Spec 独立复查均未发现剩余确定问题。Voxy 远景不等于 Xaero 地表记录，本轮不新增读取 Voxy 数据的自动命名接口。
